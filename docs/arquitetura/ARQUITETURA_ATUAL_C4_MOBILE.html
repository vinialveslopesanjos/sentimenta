Arquitetura atual do SaaS

Esta página é estática e não carrega Mermaid, PlantUML, CDN ou imagens externas. Foi criada para abrir rápido no celular via Tailscale.

FastAPI Next.js 15 Vite PWA Celery Redis PostgreSQL 16 Docker Compose

Resumo

  • Produção confirmada em VPS única com Nginx e Docker Compose.
  • Compose sobe api, web, worker, beat, postgres e redis.
  • API e web ficam publicados localmente em 127.0.0.1; Nginx faz a borda pública.
  • O fluxo crítico é sincronizar uma conexão social, ingerir posts/comentários, analisar via LLM e atualizar dashboard com dados persistidos.

Fluxo principal

Fluxo escolhido: sincronização/análise de uma conexão social. É o caminho mais representativo da promessa do produto.

Usuário inicia sync/análise

Next.js ou PWA chama POST /api/v1/connections/{id}/sync com JWT.

síncronofrontendAPI
API valida execução

FastAPI verifica rate limit, conexão, plano, créditos e se já existe run ativo.

RedisPostgreSQL
PipelineRun é criado

A API grava o run como running e retorna run_id e task_id.

persistênciaauditável
Tarefa Celery é enfileirada

A API publica task_full_pipeline no Redis; worker consome de forma assíncrona.

assíncronoRedis/Celery
Worker ingere dados reais

Instagram OAuth usa Graph API; Instagram público/TikTok/enrichment usam Apify; YouTube usa Data API ou yt-dlp.

externosingestão
Posts e comentários são persistidos

Worker faz upsert de posts/comments e registra passos e contadores no PipelineRun.

PostgreSQLrastreabilidade
Comentários pendentes são analisados

Batches são enviados para OpenRouter/Gemini; respostas viram score, polaridade, emoções, tópicos, resumo e custo.

LLMOpenRouter
Resultado final é consolidado

Worker consome créditos, invalida cache Redis, atualiza summaries e marca o run como completed ou failed.

créditoscachestatus
Frontend busca progresso e dashboard

O frontend usa polling efetivo em endpoints de pipeline/dashboard e exibe apenas dados persistidos.

Evidências e pendências

  • Confirmado: FastAPI, Next.js, PWA Vite, Celery/Redis, PostgreSQL, Nginx, Docker Compose, GitHub Actions deploy.
  • Confirmado: OpenRouter/Gemini, Apify, Instagram, TikTok, YouTube, Stripe, Resend, Google OAuth, Sentry e analytics frontend.
  • Inferido: PWA em produção como artefato estático servido por Nginx, não como container.
  • Não encontrado no runtime atual: S3/R2/GCS, NoSQL, Kafka, RabbitMQ, SQS, WhatsApp/Twilio, Kubernetes, Helm ou Terraform.

A VPS também roda outros projetos Docker fora do Sentimenta. Isso não foi desenhado como parte da arquitetura do SaaS, mas é um ponto de risco operacional por compartilhamento de recursos.
