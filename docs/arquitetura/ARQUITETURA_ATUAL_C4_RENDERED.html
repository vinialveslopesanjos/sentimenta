3. Evidências e pendências

  • Confirmado no código: FastAPI, Next.js, PWA Vite, Celery/Redis, PostgreSQL, Nginx, Docker Compose e GitHub Actions deploy.
  • Confirmado na VPS: containers api, web, worker, beat, postgres e redis; API/web saudáveis; produção no commit 4ce5a06.
  • Confirmado no código/envs: OpenRouter/Gemini, Apify, Instagram, TikTok, YouTube, Stripe, Resend, Google OAuth, Sentry e analytics frontend.
  • Não encontrado no runtime atual: S3/R2/GCS, NoSQL, Kafka, RabbitMQ, SQS, WhatsApp/Twilio, Kubernetes, Helm ou Terraform.

A VPS também roda outros projetos Docker fora do Sentimenta. Eles não são parte da arquitetura do SaaS, mas representam risco operacional por compartilhamento de CPU, memória, disco e rede.

API -> DB : Cria PipelineRun running
API ->> Redis : Enfileira task_full_pipeline
Redis ->> Worker : Entrega task
Worker -> Social : Ingestão de posts/comentários
Worker -> DB : Upsert posts/comments
Worker -> LLM : Analisa comentários em batches
LLM --> Worker : Scores e tópicos
